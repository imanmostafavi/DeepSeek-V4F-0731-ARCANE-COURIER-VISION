- title screen and click-to-start
- keyboard movement
- collision with walls and bookshelves
- enemy movement
- collectible counters
- health hearts
- pause state

- restart button
- clear visual hierarchy and readable UI
- responsive layout for both desktop and narrow mobile screens
- polished colors, shadows, particles, and distinct game states

After implementing it, open it in a browser and take screenshots at 1280x720 and 390x844. Inspect the screenshots visually for:
- overlapping or clipped UI
- unreadable text or poor contrast
- incorrect centering
- blank canvas areas
- controls covering gameplay
- inconsistent spacing
- broken game-state transitions

Fix every visual issue you find, then retest both viewport sizes. Write the file directly and reply only with a short completion note.
